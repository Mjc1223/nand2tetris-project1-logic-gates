# Nand2Tetris Project 5 – Hack Assembly Programs

This project was completed as part of my **Computer Organization (COMPORG)** course using a Nand2Tetris-based curriculum.

## Overview

This project focuses on writing programs in **Hack assembly language**. These programs interact directly with memory and input/output devices in the Hack computer system.

The goal is to understand how low-level machine instructions control program execution and manipulate memory.

## Implemented Programs

The following assembly programs were implemented:

- **Mult.asm** – multiplies two numbers stored in memory using repeated addition.
- **Fill.asm** – fills the screen when a key is pressed and clears it when no key is pressed.
- **ScreenSample.asm** – demonstrates direct manipulation of the Hack computer screen memory.

## Description

These programs demonstrate how Hack assembly instructions interact with registers, memory, and I/O devices such as the keyboard and screen.

They illustrate core concepts such as loops, conditional jumps, and direct memory manipulation.

- Hack Assembly Language
- Nand2Tetris CPU Emulator
