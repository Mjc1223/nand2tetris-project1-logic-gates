# Nand2Tetris Project 1 – Logic Gates

This project was completed as part of my **Computer Organization (COMPORG)** course using the Nand2Tetris curriculum.

## Overview

The goal of this project is to implement fundamental **combinational logic gates** using Hardware Description Language (HDL). These gates are the foundational building blocks used to construct more complex digital circuits and computer systems.

Each chip was implemented and tested using the Nand2Tetris hardware simulator.

## Implemented Chips

The following logic components were implemented:

- And
- And16
- DMux
- DMux4Way
- DMux8Way
- Mux
- Mux16
- Mux4Way16
- Mux8Way16
- Not
- Not16
- Or
- Or16
- Or8Way
- Xor

## Description

Each chip was implemented using HDL and verified using the provided `.tst` test scripts and `.cmp` comparison files in the Nand2Tetris hardware simulator.

These components serve as the foundation for later projects that implement arithmetic units, memory systems, and the full computer architecture.

## Technologies Used

- Hardware Description Language (HDL)
- Nand2Tetris Hardware Simulator
