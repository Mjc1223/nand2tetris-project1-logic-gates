# Nand2Tetris Project 4 – Machine Language

This project was completed as part of my **Computer Organization (COMPORG)** course using the Nand2Tetris-based curriculum.

## Overview

This project introduces programming in the **Hack machine language**, a low-level assembly language designed for the Hack computer platform.

The programs written in this project demonstrate arithmetic operations and control flow using assembly instructions.

## Implemented Programs

The following assembly programs were implemented:

- **Add.asm** – performs addition using Hack assembly instructions.
- **Double.asm** – doubles a value stored in memory.
- **Neg.asm** – computes the negation of a value.
- **Loop.asm** – demonstrates looping and control flow in Hack assembly language.

## Description

These programs illustrate how arithmetic operations and control structures can be implemented using low-level instructions. They interact directly with registers and memory in the Hack computer architecture.

## Technologies

- Hack Assembly Language
- Nand2Tetris CPU Emulator
