# Nand2Tetris Project 2 – Boolean Arithmetic

This project was completed as part of my **Computer Organization (COMPORG)** course using the Nand2Tetris curriculum.

## Overview

The goal of this project is to implement arithmetic circuits using Hardware Description Language (HDL). These components form the basis of the **Arithmetic Logic Unit (ALU)** used in a computer's CPU.

The circuits are built by combining previously implemented logic gates.

## Implemented Chips

The following components were implemented:

- HalfAdder
- FullAdder
- Add16
- Inc16
- ALU

## Description

These chips perform fundamental arithmetic operations including addition and incrementing values. The ALU combines these operations to perform computations on 16-bit inputs.

All components were tested using the provided `.tst` scripts and verified using `.cmp` comparison files in the Nand2Tetris hardware simulator.

## Technologies

- Hardware Description Language (HDL)
- Nand2Tetris Hardware Simulator
